    Web Editor

    Point at an element on a website and say what to do with it — that becomes a task for an agent

    The studio’s own tool. A browser for iPhone and a Chromium extension: you select an element on the page, describe the change, and out comes a task with the selector, anchors, styles and the element’s surroundings. You hand it to the agent via the clipboard, a zip file, sharing or a remote MCP server, from which the agent reads the task and checks it off on its own. The tool itself never writes to the code; it only reads the page, and the content stays on the device. Still in development, with invite-only testing.

    • Swift
    • WKWebView
    • MV3 extension
    • MCP
    • Dependency-free vanilla JS
    webeditor.click
