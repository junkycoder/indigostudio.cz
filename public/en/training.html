Claude Code and Codex: tips backed by measurements

There is plenty of advice on working with AI coding assistants, and little of it has been verified. So before a tip makes it into the training, we measure it: the same task is solved without it and with it, on several models, and we compare token usage, cost and success rate.

How we measure

  • A set of tasks from real repositories. Bug fixes, new features and refactoring, each task with tests that decide whether it is done.
  • Every tip twice. The same task without the tip and with it, repeatedly, so the result is not a fluke of a single run.
  • What we record. Input, output and cached tokens, cost, time and success rate based on tests.
  • Several models. Claude Code with Claude models and Codex with GPT models. For every result we state the tool version, the model and the date of measurement.
  • In the context of public benchmarks. We will compare our own numbers with public results such as SWE-bench Verified and Terminal-Bench.

We will publish the tasks, scripts and measured data so that anyone can verify the results or reproduce them on their own code.
