Daniel — vývojář (Capacitor / vanilla / iOS)

Dělám mobilní aplikace v Capacitoru bez zbytečných závislostí (vanilla HTML/CSS/JS + nativní iOS kód). Mám rád razor‑edge řešení, vlastní custom elements a jednoduchost. Kód pojmenovávám krátce a občas vtipně — jako weed můj web editor.

custom elements Capacitor 7 iOS native no deps
Nabídnout spolupráci

Vybrané projekty

  • weed sheet — nativní iOS overlay pro webview, vlastní bridge, skleněný efekt.
  • mijebe.cz — jednoduchý video‑feed na Cloudflare základu (HTML only, auto‑schvalování).
  • apka s intentem — parsování send-intent do JS vrstvy, logování metadat.

Kontakt

E‑mail: daniel@example.com · Lichess: @daniel

Preferuju stručné zadání a přímý přístup. Demo klidně v plain HTML.

Nabídka práce / spolupráce

Bez backendu: odeslání jen lokálně (JSON) + možnost otevřít e‑mail s předvyplněnými daty.
