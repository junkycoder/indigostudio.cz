Co stavíme

Web jako služba, ne jako artefakt.

Konkurence prodává weby jako produkt. Wix, Webnode, agentury, freelanceři — všichni vám něco vyrobí a zmizí. My prodáváme klid. Jednou zaplatíte, jednou se vrátíte, když chcete něco upravit. Jinak se to stará a roste samo.

fakan.cz je platforma s pluginy — minimální základ (přihlášení, hosting, fakturace, editor) a všechno ostatní si přidáte podle potřeby: formuláře, SEO, analytika, fulltext, komentáře, mapy, reklama, AI údržba.

Tři vstupy (mám web / chci nový / přecházím od jiných), realizaci dělá AI tým s lidským garantem, velín je vaše řídicí místo, notifikace napříč ekosystémem. Statický výstup hostovaný na Cloudflare.

Mobilní aplikace přijde ve fázi 5 a 6. Pro vývojáře je marketplace s podílem z prodejů (fáze 6+). Stáhnete si svůj web do ZIPu, kdykoliv — žádné svazování, žádný „premium export“.

Šest věcí, které děláme jinak

  • Vanilla HTML/CSS/JS/SVG. Žádný React, Vue, Next. Žádné node_modules.
  • Static-first. Web je předem vyrobený soubor, ne aplikace, která se každou návštěvou skládá od nuly.
  • Žádná okénka se souhlasem. A nedáme se přemluvit.
  • Měření bez špehování. Víme, kolik lidí přišlo, neumíme říct kdo. To je rozdíl proti Google Analytics.
  • AI s lidským garantem. Říkáme nahlas, že realizaci dělá AI tým. Garant má jméno a podpis.
  • Stáhnete si svůj web do ZIPu, zdarma, kdykoliv. Na všech tarifech.

Pět hodnot

Jak fakan.cz přemýšlí.

Bez kravin

Žádná okénka se souhlasem. Žádné popupy. Žádné „akceptujte vše“. Žádné „synergie“ a „omnichannel“.

Hned

První výsledek do minuty. Bezplatná analýza okamžitě. Úprava webu naživo za 30 sekund. Žádné „dorazí v Q3“.

Konkrétně

Místo „rychlejší“ → naběhne za 0,9 s místo 3,2 s. Místo „lepší SEO“ → 17 nových klíčových slov. Čísla, ne přídavná jména.

Lidsky

Vykáme. Krátké věty. Nešlo to → řekneme to. AI to dělá → řekneme to. Garant má jméno.

Trvanlivě

Statika. Žádný módní framework, který za dva roky umře. Váš web přežije i nás — máte export, doménu, otevřený formát.

Standardy

Každý web od nás splňuje, bez výjimky.

Nekompromisně. Zákazník nemůže říct „chci okénko se souhlasem“ a my mu ho uděláme. Když na něm trvá, je to jiný produkt mimo standard fakan.cz. Pluginy musí pravidla splnit, kernel je vynucuje při schvalování.

Soukromí Bez cookies, bez banerů

Přihlášení přes podepsaný JWT v sessionStorage. Měření bez cookies: CF Web Analytics + edge counter. GDPR-friendly defaultně.

Žádné CDN, žádné fonty zvenku Vše u nás

Bez třetích stran, fontů a CDN. Žádný Google Fonts call. Žádný Cloudflare CDN cookie. Vše na našem hostingu.

Mobile-first 375 × 812 výchozí

Plochy pro prst ≥ 44 × 44 px. Žádný hover-only. Žádný horizontální scroll. Klávesnicová navigace povinná.

Auto theming Tmavý / světlý bez přepínače

Přes prefers-color-scheme. Žádný přepínač v UI defaultně — respektujeme nastavení systému.

Přístupnost WCAG 2.2 AA minimum

Sémantický HTML, plná klávesnicová navigace, viditelný focus, test screen-readeru před vydáním.

Strukturovaná data Schema.org JSON-LD

Sitemap, robots, canonical, Open Graph + Twitter Card per stránka. Hned od prvního dne.

Rychlost Naskočí do 1,5 sekundy

LCP < 1,5 s · CLS < 0,05 · INP < 200 ms. JS < 30 kB gzip per stránka. Statické HTML, žádná aplikační vrstva navíc.

Zákonné GDPR-friendly defaultně

Nesbíráme nic, k čemu bychom potřebovali souhlas. E-mail v kontaktech jen s ověřením přes přihlašovací odkaz.

Zákaznické cesty

Čtyři dveře dovnitř a jeden velín ven.

Každý zákazník přichází jiným vchodem. Buď má web, nebo žádný nemá, nebo už u nás je, nebo migruje od konkurence. Cíl je vždycky stejný: web, který se sám stará a roste.

Cesta A · mám web

URL → analýza → realizace

URL → Turnstile → free analýza + 1 free AI redesign → mikroplatby za hlubší reporty/varianty → konfigurátor → faktura → realizace.

Cesta B · chci nový

Intake → doména → realizace

Intake → vyhledávač domén (Subreg API) → 3 free preview směry → konfigurátor → faktura → realizace. Doména objednána až po platbě.

Cesta C · existující zákazník

Magic link → velín

Magic link → velín → správa všech webů, zakázek, předplatného, marketplace, AI klíčů, týmu, fakturace.

Cesta D · migruji

Audit s číslem úspory → migrace

„Platíš za hosting moc?“ → free migrační audit s číslem úspory → self-service B1 (2 990–9 990 Kč) nebo assisted B2 (od 14 990 Kč) s lidským expertem. Doména zůstává u stávajícího registrátora.

Editor flow

Klik → změna → publish

Magic link → vybrat web → editor s manifestem → klik na prvek → změna → uložit → review → publish. Live ~30 sekund.

Cesta E · vývojář

SDK → submission → marketplace

fakan.cz/dev → registrace dev programu (Hobby zdarma) → SDK + sandbox → vývoj → submission → review → marketplace listing → recurring revenue.

Pluginová platforma

Kernel a pět vrstev pluginů.

Vše je plugin, kromě kernelu. Kernel je auth, hosting, registry, manifest engine, editor shell, velín shell, notifikační hub, billing, marketplace, storage primitiva, i18n a audit. Všechno ostatní si zapínáš.

Kernel

Minimální. Auth, plugin registry, manifest engine, editor shell, velín shell, notifikační hub, billing core, marketplace, audit, i18n. Bez kernelu nic neběží. Kernel sám není plugin.

Core pluginy povinné, MVP

forms, seo-basic, analytics-basic. Od nás. Každý web je má.

Oficiální pluginy volitelné, od nás

Fulltext (FTS5 D1), komentáře, GEO (llms.txt), PPC, sociální sítě, agregátory (Firmy.cz, Mapy.cz, GBP), BYO AI, advanced analytics, mini-kurzy, AI Údržbář.

Partnerské + komunitní

Verified partner tier (KYC, smlouvy, fáze 7+) a otevřená komunita (Hobby zdarma, fáze 6+). Vlastní Worker isolate per plugin, deklarované permissions jako mobilní apka.

Free analýza

Váš web má 6 vad. Tři vážné, tři kosmetické.

  • Načítá se 4,2 s místo doporučených 1,5 s. Lidé odcházejí.

Hosting

Static-first na Cloudflare. Path-based routing.

Každý web staticky generovaný, dynamika výhradně přes API (Workers + D1/KV/R2/DO/Queues). Vlastní doména zákazníka je primární URL, mirror na fakan.cz/{host}/ má vynucenou hlavičku X-Robots-Tag: noindex, nofollow přímo z Workeru — neindexuje se.

Anti lock-in

Váš web je váš. Vždycky.

Stáhnout web v ZIPu — od Hobby tieru, jedním klikem

Statické HTML / CSS / JS / SVG všech stránek (vygenerovaný snapshot, ne build artefakty). Kompletní asset složka (obrázky, fonty, ikony, vše self-host). README.md s návodem na lokální spuštění (python -m http.server) i nasazení na vlastní Apache / Nginx. fakan.json manifest webu — kdybyste se chtěl vrátit, rekonstruujeme z něj editor. LICENSE info: content je váš, struktura/template je MIT.

Záměrně bez tier-lockingu. Je to nejsilnější marketingový argument proti lock-inu konkurence — Webnode, Wix, WordPress.com mají export buď neexistuje, nebo je zaplacený zvlášť.
