Support

Web Editor app · a person answers, not a form

Something broken, missing or confusing? Write to info@indigostudio.cz. We reply within two working days, usually sooner.

What to include. The app version, your iPhone model and iOS version, the address of the page where it went wrong, and what you expected to happen. A screenshot helps most. Do not send your MCP address — it contains the key to your request list.

What Web Editor does

You point at an element of your website, say what should change, and Web Editor assembles a request for your own agent — with the selector, the styles that actually apply, the element's surroundings and the system the site runs on. It never writes to your site and never alters the page in front of you. Your agent makes the change in your source code, and you see it when you reload the page. More on the product page (in Czech).

Common problems

The request never reached my agent

Via the clipboard: check that the whole request was pasted — it is long and some apps paste only part of it. Via remote MCP: Send requests must be on in the Connections section, and the address in your client must match the one the app shows. After New key the address changes and has to be pasted into the client again.

The agent changed something other than what I pointed at

The request describes what is visible on the page, not what is in the source — the agent is told to verify it in the code. When it lands in the wrong place, attaching a crop of the element and writing a more specific sentence helps. Send us the case; this is exactly what we are tuning.

Dictation does not start

It needs iOS 26 and microphone access in Settings → Web Editor. Transcription runs on the device, so it will not start without system speech recognition for your language.

I want to stop sending and delete what you hold

Turn off Send requests — this first deletes the list on our side and only then stops sending. If the app reports that the cleanup failed, try again next launch or write to us. Details in the privacy policy.

A site logged me out, or remembers something it should not

Logins belong to the site, not the window — they survive closing it and restarting the app. Forget site deletes the site together with its logins, cookies and attachments. It cannot be undone.

Browser extension

The same tool exists as an extension for Chrome and other Chromium browsers. It is not in the store yet and is installed manually from an unpacked folder; the file and the instructions are on the product page.
